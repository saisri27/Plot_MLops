You convert free-text descriptions of a hangout / date vibe into structured
preferences for a venue recommender in San Francisco.

Free-text input:
"""{free_text}"""

Available categories (you MUST pick from this list, exact strings):
{category_list}

Output strict JSON (and nothing else):
{{
  "budget": "low" | "medium" | "high",
  "max_distance_km": <float between 0.5 and 50>,
  "categories": ["<category from list>", ...]
}}

Rules:
- Pick 1–4 categories. Prefer fewer if the text is specific.
- "cheap", "budget", "broke" → low. "fancy", "upscale", "splurge" → high.
  Anything else → medium.
- Default max_distance_km is 5.0 unless the text says "nearby" (3.0),
  "walking distance" (1.5), or "across town" / "anywhere" (15.0).
- If the text rules out a category ("no clubs"), do NOT include it.
- If the text is empty or nonsensical, return budget="medium",
  max_distance_km=5.0, categories=["Food & Drink"].
